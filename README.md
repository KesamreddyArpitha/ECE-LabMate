# 🚀 ECE LabMate – AI-Powered ECE Learning Application

### Gnani AI Internship Challenge

ECE LabMate is an interactive AI-powered learning application designed to help Electronics and Communication Engineering students understand concepts through AI tutoring, voice interaction, virtual experiments, and viva practice.

## ✨ Features

- 🧠 **AI ECE Tutor** – AI-powered explanations of technical concepts.
- 🔊 **AI Text-to-Speech** – Voice-based learning using Gnani AI TTS.
- 📡 **Virtual Lab** – Interactive signal generation and modulation experiments.
- 🎯 **Viva Practice** – Practice questions with answer evaluation and scoring.
- 💻 **Interactive GUI** – Developed using MATLAB App Designer.

## 🛠️ Technologies Used

- MATLAB App Designer
- Gemini AI
- Gnani AI Text-to-Speech API
- Digital Signal Processing
- Communication Systems

## 🎯 Project Objective

To make ECE learning more interactive by integrating AI-powered concept explanations, practical visualization, and self-assessment into a single application.
